# MOVE-AI 시연 시나리오

> 제출물: 시연 녹화 영상. 목표 길이 2~3분.
> 시연 장소: **B — 가온스퀘어 오피스타워** (같은 배송지에서 차량 톤수로 경로가 갈리는 유일한 데이터)
> 기획·디자인용 상세본은 `MOVE_AI_기획디자인_이해자료.pdf` 4부에 있다. 이 문서는 개발자용 요약이다.

---

## 1. 시연이 성립하려면 무엇이 동작해야 하는가

| 컷 | 필요한 기능 | Phase |
|---|---|---|
| 1~3 | 배송 건 선택 · 경로 자동 선택 · 단계별 카드 | 4 |
| 4 | 방화문 단계에 주의 카드 2장 노출 | 4 |
| 5~6 | 녹음 → STT → 기사 수정 → 추출 | 5, 6 |
| 7 | 검수 화면 · 승인 | 7 |
| 8 | 승인 직후 재조회 시 새 카드 + 배지 | 7 |
| 9 | 배송 완료 | 4 |

**Phase 4까지만 되어도 1막(컷 1~3)은 찍을 수 있다.** 2막은 Phase 7이 필요하다.

## 2. 1막 — 차량이 다르면 길이 다르다

```
컷1  배송 목록 → 가온스퀘어 12층 건 선택 → [현장 도착] → 차량 1톤 지정
컷2  ROUTE_B_01 (7단계) 안내 시작
     1단계에서 "2.3m 초과 진입 불가", "램프 곡선 서행" 카드 확인
컷3  같은 배송 건, 차량만 2.5톤으로 바꿔 재시작
     → ROUTE_B_02 (3단계) 정문·지상 로비 경로로 완전히 달라짐
```

### 필요한 API 호출

```
POST /api/guidance  { deliveryJobId: JOB_B_01, vehicle:{ tonnage:1.0, heightM:2.1 } }
   → route = ROUTE_B_01, totalSteps 7

POST /api/guidance  { deliveryJobId: JOB_B_01, vehicle:{ tonnage:2.5, heightM:2.7 } }
   → route = ROUTE_B_02, totalSteps 3
```

**같은 배송 건(`JOB_B_01`)을 두 번 시작한다.** 두 번째 호출이 막히면 컷3을 찍을 수 없다.
이전 세션은 `ABANDONED` 처리하고 새 세션을 만든다. → `05B §4-3`

`ROUTE_B_01`은 `maxTonnage 1.0`, `ROUTE_B_02`는 `minTonnage 1.0`이다.
경계 규칙(`maxTonnage`는 이하 허용, `minTonnage`는 초과만 허용)이 정확해야 1.0톤에서 두 경로가 동시에 살아남지 않는다. → `04 §11-3`

## 3. 2막 — 경험이 지식이 되어 돌아온다

```
컷4  1톤 경로 4단계 (하역장 → 방화문)
     주의 카드 2장만 있고 해법이 없는 상태를 보여줌
       K_B_012  방화문이 매우 무겁다
       K_B_013  한 손으로 밀면 박스가 쏠린다
컷5  베테랑 기사 음성 녹음
컷6  STT 확인 → AI가 지식 조각으로 분해
컷7  관리자 검수 — 원문·AI 결과·근거 구절 나란히 → 승인
컷8  ★ 같은 4단계 재조회 → 새 카드 등장 (배지)
컷9  배송 완료
```

### 시연용 신규 제보 (확정)

```
"아 방화문 옆에 요즘 고정용 고리가 걸려 있거든요.
 그거 걸어두면 문 잡고 있을 필요가 없어요.
 카트 두 번 왔다 갔다 할 때 훨씬 편합니다."
```

기대 추출 결과 (1~2건):

```
target        NODE  하역장 방화문
category      OTHER + "방화문 고정 장치"
fact_type     INSTRUCTION
movement_mode PEDESTRIAN / CART
statement     방화문 옆 고정용 고리를 걸면 문을 잡고 있지 않아도 된다.
action_text   문 옆 고정용 고리를 건다.
usage_scope   ACTION_GUIDANCE
```

**이 제보를 고른 이유** — 바로 위 `K_B_012`(방화문이 무겁다)의 **해법**이 된다.
문제 → 제보 → 해결이 한 화면에서 읽힌다. 다른 내용으로 바꾸더라도
**"기존 주의 카드를 해소하는 내용"**이라는 성질은 유지한다.

**주의** — 기존 146건과 겹치지 않아야 한다. 유사 카드가 두 장 뜨면 "원래 있던 것 아닌가"로 읽혀 핵심 장면이 무너진다.

## 4. 녹화 전 확인 목록

```
[ ] datasets 임포트 재실행 가능 (중간 초기화 대비)
[ ] 1톤 / 2.5톤 경로 분기 정상
[ ] contextTime 지정으로 시간 조건 지식 노출 제어 가능
[ ] 4단계에 K_B_012 · K_B_013 노출
[ ] 승인 → 재조회에서 isRecentlyAdded = true
[ ] AI 호출 실패 시 화면이 죽지 않고 오류 표시
[ ] 시연용 신규 제보가 기존 146건과 중복 없음
```

## 5. 시간 조건 주의

`K_B_014`(화물 엘리베이터 12:00~13:00 혼잡)는 **발표 시각이 그 범위 밖이면 필터에 걸려 사라진다.**
`POST /api/guidance`의 `contextTime`으로 시나리오 시각을 지정한다. → `04 §3-4`

## 6. 대안 — Phase 7이 못 끝났을 때

2막을 못 찍으면 1막만으로도 발표는 성립한다.
"차량에 따라 경로가 갈린다"는 일반 내비게이션과의 차별점을 그 자체로 보여준다.
다만 **"경험이 쌓인다"는 핵심 메시지가 빠지므로**, 발표에서 해당 부분은
화면 대신 구조 설명으로 대체한다. 없는 기능을 있는 것처럼 말하지 않는다.

# 7. 녹화 진행 가이드 (사람이 진행)

> **개발이 끝난 뒤 한 번에 촬영한다.** 하네스에게 시키는 작업이 아니다.
> 중간에 찍으면 나중에 화면이 바뀌어 다시 찍어야 한다.
> **총 30~40분을 확보한다.** (점검 15분 + 촬영 15분 + 확인 10분)

## 7-1. 촬영 전 30분 — 환경 고정

이걸 안 하고 찍기 시작하면 중간에 반드시 다시 찍는다.

```
[ ] DB를 임포트 직후 상태로 초기화     시연 중 쌓인 테스트 데이터가 화면에 남지 않게
[ ] 시연용 신규 제보가 아직 승인 전인지 확인   이미 승인돼 있으면 2막의 "새로 등장"이 성립 안 함
[ ] 브라우저 확대 125~150%             영상에서 글자가 읽혀야 한다
[ ] 알림·메신저 전부 끄기               팝업 하나에 다시 찍는다
[ ] 브라우저 탭 정리, 북마크바 숨기기
[ ] 개발자 도구 닫기
[ ] 화면 녹화 도구 미리 테스트           소리까지 녹음되는지 확인
```

## 7-2. 동작 점검 12항목 — 카메라 켜기 전

**하나라도 실패하면 그 컷은 대본을 수정한다.** 안 되는 걸 되는 것처럼 찍지 않는다.

### 1막이 성립하는가

```
[ ] 1  배송 목록에 JOB_B_01(가온스퀘어 12층)이 보인다
[ ] 2  차량 1톤 → 후문·지하 경로(7단계)가 나온다
[ ] 3  1단계에 "2.3m 초과 진입 불가" 카드가 뜬다
[ ] 4  같은 건을 2.5톤으로 다시 시작할 수 있고 정문·로비 경로(3단계)가 나온다
[ ] 5  두 화면의 단계 수가 눈에 띄게 다르다 (7 vs 3)
```

**5번이 1막의 전부다.** 이게 안 보이면 1막을 찍을 이유가 없다.

### 2막이 성립하는가

```
[ ] 6   1톤 경로 4단계에 주의 카드 2장이 뜬다 (방화문 무거움 / 박스 쏠림)
[ ] 7   녹음 버튼이 실제로 마이크를 잡는다
[ ] 8   STT 결과가 화면에 뜨고 수정이 가능하다
[ ] 9   AI가 지식 조각으로 나눈 결과가 카드로 보인다
[ ] 10  검수 화면에 원문과 근거 구절이 함께 보인다
[ ] 11  승인 직후 같은 4단계에 새 카드가 나타난다
[ ] 12  새 카드에 "새로 추가된 팁" 배지가 붙는다
```

**11번이 2막의 전부다.** 승인 전후 화면이 달라지지 않으면 2막의 의미가 없다.

### 실패했을 때

| 실패 | 대응 |
|---|---|
| 4·5 실패 | 1막 포기. 발표는 지식 순환(2막)만으로 구성 |
| 7·8 실패 | 컷5를 **텍스트 직접 입력**으로 바꿔 촬영. 대사는 "말로 남긴 내용을 확인하고" |
| 9 실패 | 컷6 생략. 검수 화면에서 결과만 보여주고 넘어감 |
| 11 실패 | **2막 포기.** 없는 기능을 있는 것처럼 찍지 않는다 |
| 12만 실패 | 촬영 진행. 대신 마우스로 새 카드를 가리키며 말로 짚는다 |

## 7-3. 촬영 순서

**컷을 나눠 찍는다.** 한 번에 끝까지 가려다 실수하면 처음부터 다시다.

```
1막   컷1 → 컷2 → 컷3          약 40초
2막   컷4 → 컷5 → 컷6 → 컷7 → 컷8 → 컷9   약 90초
```

### 각 컷에서 반드시 잡아야 하는 것

| 컷 | 화면에 꼭 보여야 할 것 | 머무는 시간 |
|---|---|---|
| 1 | 차량 톤수를 **1톤으로 고르는 순간** | 2초 |
| 2 | **7단계**라는 표시, 카드 2장 | 4초 |
| 3 | 차량을 **2.5톤으로 바꾸는 순간**, 그리고 **3단계** | 5초 |
| 4 | 주의 카드 2장 **그리고 그 아래 아무것도 없음** | 4초 |
| 5 | 녹음 중 표시 | 발화 길이 |
| 6 | 원문 한 줄 → 카드 여러 장으로 나뉜 화면 | 4초 |
| 7 | 원문과 AI 결과가 **나란히 있는 화면**, 승인 클릭 | 4초 |
| 8 | **컷4와 같은 화면인데 카드가 늘어난 것** | 5초 |
| 9 | 배송 완료 버튼 클릭 | 2초 |

**컷4와 컷8은 같은 화면 구도로 찍는다.** 나란히 붙였을 때 차이가 한눈에 보여야 한다.
스크롤 위치까지 맞추면 좋다.

### 마우스 사용

새로 생긴 카드를 **마우스로 천천히 가리킨다.** 영상에서 시선을 유도하는 유일한 수단이다.
빠르게 움직이면 아무도 못 따라온다.

## 7-4. 촬영 후 확인

```
[ ] 화면 글자가 읽히는가 (모바일에서도 재생해 볼 것)
[ ] 컷4 → 컷8 차이가 한눈에 보이는가      ← 가장 중요
[ ] 1톤 7단계 / 2.5톤 3단계 대비가 보이는가
[ ] 음성이 들리는가
[ ] 개인정보·다른 창·알림이 화면에 잡히지 않았는가
[ ] 길이가 2~3분 안인가
```

**컷4 → 컷8 차이가 안 보이면 다시 찍는다.** 그 장면 하나가 이 서비스의 전부다.

## 7-5. 시간이 없을 때 자르는 순서

```
1. 컷6 (AI 분해 화면)      → 검수 화면에서 결과만 보여주면 됨
2. 컷9 (배송 완료)         → 없어도 흐름이 성립
3. 컷1 (배송 목록)         → 안내 화면부터 시작
4. 1막 전체               → 2막만으로도 핵심 메시지는 전달됨
```

**절대 자르지 않는 것 — 컷4와 컷8.** 이 둘이 빠지면 찍을 이유가 없다.
