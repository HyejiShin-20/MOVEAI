# MOVE-AI 시연 시나리오

> 제출물: 시연 녹화 영상. 목표 길이 2~3분.
> 시연 장소: **B — 가온스퀘어 오피스타워** (같은 배송지에서 차량 톤수로 경로가 갈리는 유일한 데이터)
> 기획·디자인용 상세본은 `MOVE_AI_기획디자인_이해자료.pdf` 4부에 있다. 이 문서는 개발자용 요약이다.

---

## 1. 시연이 성립하려면 무엇이 동작해야 하는가

| 컷 | 필요한 기능 | Phase |
|---|---|---|
| 1~3 | 배송 건 선택 · 경로 자동 선택 · 단계별 카드 | 4 |
| 4 | 방화문 단계에 주의 카드 2장 노출 | 4 |
| 5~6 | 녹음 → STT → 기사 수정 → 추출 | 5, 6 |
| 7 | 검수 화면 · 승인 | 7 |
| 8 | 승인 직후 재조회 시 새 카드 + 배지 | 7 |
| 9 | 배송 완료 | 4 |

**Phase 4까지만 되어도 1막(컷 1~3)은 찍을 수 있다.** 2막은 Phase 7이 필요하다.

## 2. 1막 — 차량이 다르면 길이 다르다

```
컷1  배송 목록 → 가온스퀘어 12층 건 선택 → [현장 도착] → 차량 1톤 지정
컷2  ROUTE_B_01 (7단계) 안내 시작
     1단계에서 "2.3m 초과 진입 불가", "램프 곡선 서행" 카드 확인
컷3  같은 배송 건, 차량만 2.5톤으로 바꿔 재시작
     → ROUTE_B_02 (3단계) 정문·지상 로비 경로로 완전히 달라짐
```

### 필요한 API 호출

```
POST /api/guidance  { deliveryJobId, vehicle:{ tonnage:1.0, heightM:2.1 } }
   → route = ROUTE_B_01, totalSteps 7

POST /api/guidance  { deliveryJobId, vehicle:{ tonnage:2.5, heightM:2.7 } }
   → route = ROUTE_B_02, totalSteps 3
```

`ROUTE_B_01`은 `maxTonnage 1.0`, `ROUTE_B_02`는 `minTonnage 1.0`이다.
경계 규칙(`maxTonnage`는 이하 허용, `minTonnage`는 초과만 허용)이 정확해야 1.0톤에서 두 경로가 동시에 살아남지 않는다. → `05 §11-3`

## 3. 2막 — 경험이 지식이 되어 돌아온다

```
컷4  1톤 경로 4단계 (하역장 → 방화문)
     주의 카드 2장만 있고 해법이 없는 상태를 보여줌
       K_B_012  방화문이 매우 무겁다
       K_B_013  한 손으로 밀면 박스가 쏠린다
컷5  베테랑 기사 음성 녹음
컷6  STT 확인 → AI가 지식 조각으로 분해
컷7  관리자 검수 — 원문·AI 결과·근거 구절 나란히 → 승인
컷8  ★ 같은 4단계 재조회 → 새 카드 등장 (배지)
컷9  배송 완료
```

### 시연용 신규 제보 (확정)

```
"아 방화문 옆에 요즘 고정용 고리가 걸려 있거든요.
 그거 걸어두면 문 잡고 있을 필요가 없어요.
 카트 두 번 왔다 갔다 할 때 훨씬 편합니다."
```

기대 추출 결과 (1~2건):

```
target        NODE  하역장 방화문
category      OTHER + "방화문 고정 장치"
fact_type     INSTRUCTION
movement_mode PEDESTRIAN / CART
statement     방화문 옆 고정용 고리를 걸면 문을 잡고 있지 않아도 된다.
action_text   문 옆 고정용 고리를 건다.
usage_scope   ACTION_GUIDANCE
```

**이 제보를 고른 이유** — 바로 위 `K_B_012`(방화문이 무겁다)의 **해법**이 된다.
문제 → 제보 → 해결이 한 화면에서 읽힌다. 다른 내용으로 바꾸더라도
**"기존 주의 카드를 해소하는 내용"**이라는 성질은 유지한다.

**주의** — 기존 146건과 겹치지 않아야 한다. 유사 카드가 두 장 뜨면 "원래 있던 것 아닌가"로 읽혀 핵심 장면이 무너진다.

## 4. 녹화 전 확인 목록

```
[ ] datasets 임포트 재실행 가능 (중간 초기화 대비)
[ ] 1톤 / 2.5톤 경로 분기 정상
[ ] contextTime 지정으로 시간 조건 지식 노출 제어 가능
[ ] 4단계에 K_B_012 · K_B_013 노출
[ ] 승인 → 재조회에서 isRecentlyAdded = true
[ ] AI 호출 실패 시 화면이 죽지 않고 오류 표시
[ ] 시연용 신규 제보가 기존 146건과 중복 없음
```

## 5. 시간 조건 주의

`K_B_014`(화물 엘리베이터 12:00~13:00 혼잡)는 **발표 시각이 그 범위 밖이면 필터에 걸려 사라진다.**
`POST /api/guidance`의 `contextTime`으로 시나리오 시각을 지정한다. → `04 §3-4`

## 6. 대안 — Phase 7이 못 끝났을 때

2막을 못 찍으면 1막만으로도 발표는 성립한다.
"차량에 따라 경로가 갈린다"는 일반 내비게이션과의 차별점을 그 자체로 보여준다.
다만 **"경험이 쌓인다"는 핵심 메시지가 빠지므로**, 발표에서 해당 부분은
화면 대신 구조 설명으로 대체한다. 없는 기능을 있는 것처럼 말하지 않는다.
