# MOVEAI Front Checkpoint

## 완료 범위
- 웹 로그인 화면
- 웹 회원가입/기사 정보 입력 화면
- M-01 메인 화면
- M-02 음성 녹음 화면
- M-03 음성 업로드 화면
- M-04 STT 결과 확인 화면
- M-06/07 장소 지정 화면

## 작업 기준
- React 18 + Vite + TypeScript
- 기존 plain CSS 구조 유지
- Figma 디자인의 최신/Updated 프레임 우선 적용
- Tailwind 추가 설치하지 않음
- 화면 이동은 react-router-dom 기준으로 연결
